# FILMING TOOLS

The normal story route remains focus-driven. For recording/replay work, a separate debug-only decision category is included so the current canonical outbreak can be reproduced without waiting for focus completion.

## Access

Launch HOI4 with `-debug`. The category `撮影・デバッグ用ストーリー操作` is only visible while debug mode is active and only exposes the East-side sequence while playing EJP.

## Reproducible sequence

1. `[DEBUG] 土岐市核融合炉への攻撃を発生`
2. `[DEBUG] 関連レーザー基地の掌握を発生`
3. `[DEBUG] 西日本防空網への侵入を発生`
4. `[DEBUG] 日本アルプス大突破を開始`

The decisions mirror the same events/modifiers used by the normal focus route and have zero AI weight. They are not intended as ordinary gameplay decisions.

## Canon guardrails

The filming controls do not assign a formal name to the reactor or laser facility, do not invent a responsible unit/person, and do not alter the confirmed side alignment of 魔理沙 (East) / 霊夢 (West).
